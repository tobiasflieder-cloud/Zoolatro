## 2. Glanz-Stocken reparieren
Ursache 1: Das Glanzbild ist 250 % breit und wird **wiederholt** (`background-repeat` Standard). Bei jedem zweiten Durchlauf steht eine
Kopie des Streifens mitten auf der Karte und verschwindet ruckartig. → `background-repeat:no-repeat` (oben schon drin).
Ursache 2: `render()` baut Team-Leiste, Bewerbermappe und Hand neu auf, die Animation startet dabei von vorn.
→ Gemeinsame Uhr: beim Erzeugen der Glanz-Schicht eine **negative** Verzögerung setzen, damit sie dort weiterläuft, wo sie war:
```js
const glzD=(sek,i)=>`--d:-${(((performance.now()/1000)+i*0.6)%sek).toFixed(2)}s`; // i = Position, damit nicht alle gleichzeitig glänzen
// <span class="glz" style="${glzD(r2?4.5:7,i)}"></span>
```
- Dasselbe Wiederholungs-Problem hat das Holo der Veredelung (`body.fxp .card[data-ed]::before`, Z. ~758): dort ebenfalls `no-repeat`
  und die gleiche Verzögerung (z. B. über `--d` am Karten-Element).

## 4. Tutorial: große Karte in der Mitte (nur nach Übernahme von `godot-daten`)
Häppchen können eine Karte groß in der Bildschirmmitte zeigen (z. B. `{t:'…', karte:'giraffen', leuchten:['show']}`), mit abgedunkeltem
Hintergrund; `leuchten` hebt Teile der Karte hervor (Merkmal-Symbol, Kosten, Form, Werte). Die Karte bleibt, solange Häppchen sie nennen,
und verschwindet beim nächsten Häppchen ohne Karte. Im Querformat steht die Karte neben der Textbox. (Noch kein Einsatz in Zoo 1 nötig,
nur die Möglichkeit plus Test.)
