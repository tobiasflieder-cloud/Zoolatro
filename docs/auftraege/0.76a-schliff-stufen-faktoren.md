## 5. Prozente werden Faktoren (leicht abgeschwächt)
Heute werden alle „+X % B/N“ eines Gebäudes **zusammengezählt** (`docs/regeln.md` Abschnitt 2, Schritt 5, und 13.12),
die ×-Faktoren dagegen nacheinander multipliziert. Neu: alles wird ein Faktor und **nacheinander multipliziert**.
- Umrechnung: **+X % → ×(1 + 0,8 · X/100), gerundet auf 0,05.** Beispiele: +20 % → ×1,15 · +25 % → ×1,2 · +30 % → ×1,25 ·
  +40 % → ×1,3 · +50 % → ×1,4 · +60 % → ×1,5. Abzüge unverändert als Faktor: −5 % → ×0,95, −10 % → ×0,9.
- „Je …“-Boni (z. B. „+20 % B und N für jedes Savannen-Gehege“, „+40 % B je Attraktion“): je Stück der Faktor, also hoch n
  (×1,15ⁿ). Obergrenzen wie „höchstens +60 %“ / „+120 %“ in Faktoren umrechnen (×1,5 / ×2).
- **Alle Texte** anpassen: Karten (`texte_de.json`, `fx`), Futter, Prägungen, Veredelungen (`EDS`), Spezialisten, Förderprogramme, Werbung,
  Merkmale (`tagfx`), Hilfe, Glossar. Schreibweise „×1,2 B“, „×1,15 B und N“. Danach `grep -n "% B\|% N\|%"` auf Reste prüfen.
- **Referenzfälle neu erzeugen** (`node tests/referenz/referenz.js erzeuge`) und in der Zusammenfassung nennen, welche Fälle sich wie stark
  ändern (grob: stärker, wenn viele Boni zusammenkommen).
